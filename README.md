# Skull Multimarcas

Landing page institucional da Skull Multimarcas, construída com Next.js, TypeScript, Tailwind CSS e Framer Motion.

## Rodar localmente

```bash
npm install
npm run dev
```

Abra `http://localhost:3000`.

## Comandos

- `npm run dev` — ambiente de desenvolvimento
- `npm run lint` — validação TypeScript
- `npm run build` — build de produção
- `npm run start` — servidor de produção

As imagens da marca ficam em `public/images`. As áreas de coleções e Instagram foram preparadas para receber fotos reais futuramente, sem usar conteúdo genérico.

Antes de publicar, defina `NEXT_PUBLIC_SITE_URL` com o domínio final para gerar a URL canônica e os metadados Open Graph corretos.
